# COMMIT//24

**24 Stunden. Ein Repo. Kein Zurück.**

Der Entwicklermarathon (Hackathon) für Deutschland, Österreich und die Schweiz. Zum Start fällt das Thema, du legst ein leeres GitHub-Repo an und baust 24 Stunden lang. Danach bewertet eine Jury in fünf Kategorien.

- **Start (vorläufig):** Samstag, 6. März 2027, 10:00 Uhr MEZ
- **Wer:** Solo oder Teams bis vier Personen aus dem D-A-CH-Raum
- **Was:** Jede Sprache, jedes Framework. KI-Tools sind erlaubt, wenn du sie in der README nennst.
- **Seite:** Der Link steht rechts oben unter „About“.

## Anmelden

Die Anmeldung läuft per Pull Request. Die Seite erzeugt dir die Datei, du legst sie unter `teilnehmer/DEIN-USERNAME.md` an. Wird dein Pull Request gemergt, stehst du auf der Startliste. Alles Weitere kommt über dieses Repo: Beobachte es über „Watch“.

## Kategorien

| Kategorie | Worum es geht |
|---|---|
| Kühnste Idee | Warum ist da noch niemand draufgekommen? |
| Sauberster Code | Struktur, Lesbarkeit, Tests, README |
| Beste Oberfläche | Design und Bedienung |
| Bester KI-Einsatz | KI als echter Teil des Produkts |
| Publikumspreis | Die Community stimmt ab |

In jeder Kategorie gibt es Platz 1 bis 3, dazu einen Gesamtsieg.

## Regeln

1. Das Repo wird erst nach dem Start angelegt. Die Zeitstempel der Commits zählen.
2. Das Repo ist öffentlich und steht unter einer Open-Source-Lizenz.
3. Bibliotheken sind erlaubt, fertige eigene Projekte von vorher nicht.
4. Nach 24 Stunden ist Schluss. Spätere Commits werden nicht bewertet.
5. Abgabe: README mit Beschreibung, Startanleitung und nach Möglichkeit einer Demo.

## Noch etwas

Die Seite hat eine Tür. Mehr sagen wir nicht.
